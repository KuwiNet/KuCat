## 用法：
先安装原版KuCat主题
然后再运行
```
wget --no-check-certificate -O /tmp/install-kucat.sh https://raw.githubusercontent.com/KuwiNet/KuCat/js/install-kucat.sh && chmod +x /tmp/install-kucat.sh && sh /tmp/install-kucat.sh
```
